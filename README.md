## 🌟 Why LocalConvert?

Most online file converters force you to upload private documents, photos, and records to remote third-party servers.

**LocalConvert is built on a single core principle:**  
*Your files should never leave your device.*

Everything runs on your own machine at `http://127.0.0.1:5000`. No internet required after setup.

## ⚡ Quick Start

### Step 1 — Clone the Repository

Open your terminal (on Windows: press `Win + R`, type `cmd`, hit Enter) and run:

```bash
git clone https://github.com/saikarthan/LocalConvert.git
cd LocalConvert
```

> **Don't have Git?** Download it from [git-scm.com](https://git-scm.com/downloads), install it, then run the two commands above.

---

### Step 2 — Launch the App

#### 🪟 Windows Users
1. Open the `LocalConvert` folder on your computer.
2. Double-click **`run.bat`**.
3. A terminal window will open — it automatically installs all required packages.
4. Your browser opens at `http://127.0.0.1:5000` with LocalConvert ready to use!

#### 🍎 Mac / 🐧 Linux Users
1. Open your terminal inside the `LocalConvert` folder.
2. Run:
```bash
./run.sh
```
3. Your browser opens at `http://127.0.0.1:5000` with LocalConvert ready to use!

> **Note:** The first launch takes ~1 minute to install Python packages automatically. Every launch after that is instant.

---

### Step 3 — Start Converting!

- Click any tool from the home screen (e.g. **"JPG to PNG"**, **"Merge PDF"**, **"Password Generator"**).
- Drop your file or click to browse and select it.
- Click **Run** — your converted file downloads instantly to your device.
- **Nothing is ever uploaded. Everything runs locally.**

## 🛠️ Features (60+ Local Tools)

- 🖼️ **Image Tools**: JPG / PNG / WebP / BMP conversion, Compression, Resizing, Cropping, Rotation, EXIF & Metadata Stripping (removes GPS/camera tags), Base64 encoding/decoding.
- 📄 **PDF Tools**: Merge, Split, Rotate, Extract Pages, Page Counter, Compress, Watermark, Text to PDF, JPG to PDF, PDF to Word, PDF to PowerPoint, Password Protection.
- 🎥 **Video & Audio**: Extract Audio (MP3/WAV), Compress Video, Audio Format Converter (MP3/WAV/FLAC/AAC/OGG).
- 🔤 **Text Tools**: Word & Character Counter, Case Converter, Remove Duplicate Lines, Line Sorting, Whitespace Cleaner, Find & Replace (Regex), Text Statistics.
- 🛠️ **Dev Tools**: JSON Formatter & Minifier & Validator, CSV ↔ JSON, URL Encoder/Decoder, Base64 String, UUID Generator, Password Generator, QR Code Generator, Color Converter (HEX/RGB/HSL).

### How to Contribute:
1. **Fork** the repository on GitHub.
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/LocalConvert.git`
3. Create a new branch: `git checkout -b feature/awesome-tool`
4. Make your changes and commit: `git commit -m 'Add awesome local tool'`
5. Push to your branch: `git push origin feature/awesome-tool`
6. Open a **Pull Request** on GitHub.
