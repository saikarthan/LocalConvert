# LocalConvert

**100% Local File Conversion & Security Toolbox**  
*No Cloud. No Data Uploads. Zero Tracking.*

---

## 🔒 Security & Zero-Server Architecture
LocalConvert runs entirely on your local machine (`127.0.0.1`). Files are never transmitted over the internet or saved to remote servers. All file processing, PDF conversions, image compression, metadata stripping, and developer utilities are performed strictly in memory and local storage.

---

## ⚡ Quick Start (Zero Setup)

### 🪟 Windows Users
Double-click `run.bat`

### 🍎 Mac / 🐧 Linux Users
Run `./run.sh`

> **Automatic Setup**: `app.py` handles missing dependencies on the fly on first launch and opens your default browser automatically.

## 🛠️ Features & Tools

### 🖼️ Image Tools
- **JPG ↔ PNG ↔ WebP Converter**: High-fidelity format conversion.
- **Image Compressor & Resizer**: Control dimensions and compression ratio.
- **EXIF Metadata Stripper**: Wipes GPS coordinates, camera serials, and privacy tags from photos.
- **Image Cropper & Rotator**: Precise pixel cropping and 90°/180° rotation.
- **Base64 Encoder / Decoder**: Convert images to data URIs or raw Base64 strings.

### 📄 PDF Tools
- **Merge & Split PDF**: Combine multiple PDFs or extract page ranges.
- **PDF Compressor**: Reduce file size with adjustable compression.
- **Rotate & Extract Pages**: Reorder or extract selected pages.
- **PDF Watermark**: Add customizable text watermarks.
- **Password Protection**: Encrypt or unlock PDF files with AES-256.
- **Format Converters**: JPG to PDF, PNG to PDF, Text to PDF, PDF to Word, PDF to PowerPoint.

### 🎥 Video & Audio
- **Extract Audio**: Convert video to MP3 or uncompressed WAV.
- **Compress Video**: Downscale to 720p with efficient encoding.
- **Audio Converter**: Convert between MP3, WAV, FLAC, AAC, OGG, M4A, and Opus.

### 📝 Text Utilities
- **Case Converter**: Sentence case, Title Case, UPPERCASE, lowercase.
- **Duplicate Line Remover & Line Sorter**: Clean up lists instantly.
- **Whitespace Cleaner & Find/Replace**: Regex-powered text processing.
- **Word & Character Counters**: Real-time reading and speaking stats.

### 💻 Developer Tools
- **JSON Utilities**: Formatter, Minifier, Validator, CSV ↔ JSON converter.
- **URL & Base64 Tools**: UTF-8 safe encoding and decoding.
- **Generators**: Cryptographic UUID v4 generator, Strong Password generator, QR Code generator.
- **Color Converter**: HEX ↔ RGB ↔ HSL live converter.
