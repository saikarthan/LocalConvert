# LocalConvert

> **100% Local File Conversion & Security Toolbox**  
> **Zero Server. Zero Cloud Uploads. 100% Private.**

LocalConvert is a local desktop application for converting, processing, and editing files directly on your computer. All processing happens 100% locally on your machine at `127.0.0.1` — your files never touch the internet.

---

## ⚡ How to Run

### 🪟 Windows
Double-click **`run.bat`**

### 🍎 Mac / 🐧 Linux
Run **`./run.sh`** in your terminal.

> **Zero Setup Needed**: The app automatically checks and installs any missing Python packages on first launch, starts the local server, and opens your default web browser automatically.

---

## 🛠️ Integrated Tools

- **Image Tools**: JPG ↔ PNG ↔ WebP converter, Image Cropper, Resizer, Compressor, EXIF Metadata Stripper, Image ↔ Base64, Image Rotator.
- **PDF Tools**: Merge PDF, Split PDF, Rotate PDF, Extract Pages, Page Counter, Compress PDF, Watermark PDF, Image to PDF, Text to PDF, Password Protection / Unlock.
- **Video & Audio**: Extract Audio (MP3 / WAV), Compress Video, Audio Format Converter.
- **Text Utilities**: Case Converter, Duplicate Line Remover, Line Sorter, Whitespace Cleanup, Find & Replace (Regex), Word & Character Counter, Text Statistics.
- **Developer Tools**: JSON Formatter, Minifier & Validator, CSV ↔ JSON Converter, URL Encoder/Decoder, Base64 Text, UUID Generator, Password Generator, QR Code Generator, Color Converter (HEX/RGB/HSL).

---

## 🔒 Security & Privacy First
- **100% Local Processing**: Operates on `127.0.0.1` (localhost).
- **No Data Leakage**: Your sensitive documents, photos, and files never leave your computer.
- **Open Source**: Full source code inspectable in `app.py` and `templates/index.html`.
